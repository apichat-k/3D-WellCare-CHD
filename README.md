# 3D WellCare CHD

3D Viewer ร้านขายยาเวลล์แคร์ (WELL CARE Pharmacy) — WebApp แบบไฟล์เดียว สร้างด้วย three.js (ฝังไว้ในไฟล์ ไม่ต้องใช้อินเทอร์เน็ต)

## ใช้งาน
- เปิด `index.html` ในเบราว์เซอร์ หรือเข้าผ่าน GitHub Pages
- ลากเมาส์ซ้าย = หมุน · ขวา/Shift = เลื่อน · ล้อ = ซูม · W A S D = เดิน
- คลิกวัตถุเพื่อดูขนาด · 📏 วัดระยะ · 📷 บันทึกภาพ

## แก้ไขขนาด
ขนาดทั้งหมด (หน่วย: เมตร) ประมาณจากภาพ SketchUp แก้ได้ที่ตัวแปร `LAYOUT` ใน `index.html`
